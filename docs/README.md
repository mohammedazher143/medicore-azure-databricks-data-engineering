# MediCore Data Platform Documentation

This folder contains the architecture and project documentation for the MediCore Azure Data Engineering portfolio project.

## Project architecture

- **Azure Data Factory:** Pipeline orchestration and metadata-driven ingestion
- **Azure Data Lake Storage Gen2:** Landing, Bronze, Silver, and Gold containers
- **Azure Databricks:** Data cleansing, transformation, and dimensional modelling
- **Azure SQL Database:** Pipeline metadata, watermarks, audit logs, and file tracking
- **Azure Key Vault:** Secure secret management
- **GitHub:** Version control and project documentation

## Planned capabilities

- Full and incremental data loads
- Watermark-based processing
- Metadata-driven pipelines
- Data quality checks and quarantine
- Star schema for reporting
- Execution logging and failure handling

## Security

This repository must not contain real patient information, credentials, passwords, access keys, or connection strings.
